How one rebalance works

All three steps happen in a single transaction.

1Buy discounted MUSDThe vault sells BTC for MUSD on the Mezo Pools MUSD/BTC pool. The swap must return more MUSD than the oracle value of the BTC sold.
2Redeem at $1The MUSD is redeemed through the MUSD TroveManager, which pays $1 of BTC per MUSD at the oracle price, minus the redemption fee.
3Keep the differenceIf the vault did not gain BTC, everything reverts. Otherwise the caller gets the bounty and the rest raises the value of every share.
